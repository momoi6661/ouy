# 策略：威科夫（吸筹 / 派发）

核心：大资金在一段横盘区间里悄悄建仓（吸筹）或出货（派发），区间结束后才是真正的趋势。通过量价关系判断区间属于哪一种，在区间末端入场。

## 吸筹区间的几个阶段（下跌之后的横盘）
- 恐慌抛售（SC）：放巨量急跌后出现长下影，随后自动反弹（AR）。这两个点定出区间的下沿和上沿。
- 二次测试（ST）：回到下沿附近但成交量明显缩小，说明抛压在减弱。
- 弹簧（Spring）：跌破区间下沿后迅速收回，扫掉最后的止损。这是吸筹区间里最好的做多点。
- 强势信号（SOS）：放量上涨突破区间上沿。
- 最后支撑点（LPS）：突破后缩量回踩区间上沿不破。这是第二个做多点。

## 派发区间（上涨之后的横盘）
方向全部相反：抢购高潮（BC）、自动回落、二次测试、上冲回落（UTAD，冲破上沿后收回，是最好的做空点）、弱势信号（SOW，放量跌破下沿）、最后供应点（LPSY，缩量反抽下沿不过）。

## 判断是吸筹还是派发
- 区间内下跌时放量、上涨时缩量 → 更像派发；上涨放量、下跌缩量 → 更像吸筹。
- 区间出现在长期下跌之后更可能是吸筹，长期上涨之后更可能是派发。
- 判断不出来时，等弹簧或上冲回落出现后再定方向。

## 入场与止损
- 弹簧做多：收回区间内后进，止损放在弹簧的最低点之下。目标先看区间上沿，再看突破后的延伸。
- 回踩确认做多：突破上沿后缩量回踩不破时进，止损放回区间内 1/3 处。
- 做空反过来。

## 注意
- 这是波段级别的方法，适合 1H / 4H / 1D。在 1 分钟图上套用没有意义。
- 弹簧之后必须有量能配合的上涨，否则可能是真的破位。

## 三条基本法则
- 供求：买盘大于卖盘价格涨，反之跌。看量价就是在看供求谁占上风。
- 因果：横盘（因）积累得越久、换手越充分，之后的趋势（果）才可能越大。
- 努力与结果：成交量是努力，价格变动是结果。放了很大的量价格却走不动，说明对手盘在接，趋势要变；量不大价格却走得很顺，说明没有阻力。

## 区间的五个阶段
A 停止原来的趋势（恐慌抛售、自动反弹）→ B 在区间里反复换手（时间最长）→ C 测试（弹簧 / 上冲回落，把最后的止损扫掉）→ D 朝突破方向走出强势（强势信号、最后支撑点）→ E 离开区间进入趋势。
能交易的只有 C 和 D：C 就是「假突破反转」，D 就是「突破回踩确认」。A 和 B 阶段方向未定，按区间两头做或者不做。

## 出处与可信度
- Richard D. Wyckoff 二十世纪初的课程；现代整理见 Wyckoff Analytics 和 StockCharts ChartSchool 的「Wyckoff Method」。
- 吸筹 / 派发是事后才能确认的叙事：同样的横盘在走完之前没人知道是哪一种。可靠的是它的两个入场点（刺穿后收回、突破后缩量回踩），这两个各有独立的依据；不要因为「看着像吸筹」就提前建仓。
