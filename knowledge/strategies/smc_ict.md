# 策略：聪明钱概念（SMC / ICT）

核心：大资金建仓需要对手盘，所以价格常常先去扫掉一侧的止损（流动性），再朝真正的方向走。SMC 用市场结构、流动性、订单块、失衡缺口来找「扫完止损之后」的入场点。

## 基本概念
- 市场结构：上升趋势是更高的高点和更高的低点，下降趋势相反。
  - BOS（结构突破）：顺着原趋势突破前高 / 前低，趋势延续。
  - CHoCH（结构转变）：逆着原趋势突破最近的关键高低点，是趋势可能反转的第一个信号。
- 流动性：前高上方、前低下方、等高 / 等低点、整数关口附近堆着大量止损单和突破单。价格容易先去「拿」这些流动性。
- 流动性扫荡：价格刺穿前高或前低后迅速收回（长影线、收盘回到区间内）。
- 订单块（OB）：一段强势单边行情启动前的最后一根反向 K 线所在的价格区域。价格回到这里时常有反应。
- 失衡缺口（FVG）：三根 K 线中，第一根的高点和第三根的低点之间没有重叠的那段空白（下跌时相反）。价格倾向于回补缺口的一部分再继续。
- 溢价区 / 折价区：一段波段的 50% 以上是溢价区（适合找空），以下是折价区（适合找多）。

## 标准入场流程（做多为例）
1. 大周期（4H / 1H）方向向上，或者刚出现向上的 CHoCH。
2. 价格回调，扫掉一个明显的前低（流动性扫荡）后收回。
3. 小周期（15m / 5m）出现向上的 CHoCH 或 BOS，确认方向转回。
4. 在这段上涨留下的订单块或失衡缺口里挂限价多单（位于折价区更好）。
5. 止损放在被扫的那个低点之外。
6. 目标：上方最近的流动性（前高、等高点），分批止盈。

做空把方向全部反过来。

## 与本项目的行情快照对应
- 快照里的 structure、摆动高低点可以直接用来判断 BOS / CHoCH。
- 长影线 + 收回前高前低 = 流动性扫荡，和「假突破反转」策略是同一件事。
- 订单块和缺口需要用 K 线数据自己识别：找最近一段位移（连续大实体、放量）之前的最后一根反向 K 线，以及位移中间没有重叠的区域。

## 注意
- 订单块和缺口很多，只用「造成了结构突破」的那一个，并且要有流动性扫荡在前。
- 大周期方向优先。逆大周期的 CHoCH 只做到最近的流动性就走。
- 被价格多次回踩过的订单块会失效，只用第一次回踩。

## 出处与可信度
- 出自 Michael Huddleston（网名 ICT，Inner Circle Trader）在网上的教学，近几年在零售交易圈流行；没有经过独立的统计检验。
- 它的大部分概念是老方法换了名字：结构突破就是道氏理论的高低点；流动性扫荡就是威科夫的弹簧、Raschke 的海龟汤；失衡缺口是价格走得太快留下的未成交空白。
- 能客观定义的部分可以用，而且程序已经算好：结构转折（BOS / CHoCH）在【转折】里，刺穿后收回在 windows 的读数里。
- 「机构在猎杀散户止损」这类叙事无法验证，不要写进理由。理由要落在可检查的事实上：哪个位置被刺穿、收盘在哪、结构变没变。
