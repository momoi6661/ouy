# 纪律清单

## 开仓的硬条件（只有这三条，缺一条都不开；过了这三条就做，不要自己再加条件。例外：候选位标了「没有优势」的打法，要有额外依据才做，没有就选 no_edge；出手尺度是「积极」时没有这条例外，按趋势做）
1. 止损能放在一个明确的结构位之外（前高前低、区间边界、均线、突破位），止损被打说明判断确实错了。
2. 到第一目标的净盈亏比（扣掉往返手续费和点差，由程序核对）达到【出手尺度】要求的下限。
3. 没有工具明确返回的反对信号：资金费率极端且站在对面、盘口价差大到吃掉目标利润、已到当日亏损上限。
   查不到的信息（新闻、财经日历、持仓量历史）不算反对信号。

## 决定仓位和信心的加分项（不是硬条件）
- 顺着大周期方向：加分，可以用满风险额度。逆大周期只做明确的区间边缘或关键位上的反转，仓位减半（plan 的 risk_pct 填上限的一半）。
- 入场周期有确认信号（放量、吞没、长影线、回踩不破）：加分，可以现价就进（entry_type=now）。
  没有确认信号时把入场区间放在结构位上等（entry_type=pullback），让价格来找你。
- BTC 同向：加分。BTC 明显反向时，山寨币仓位减半。
出手尺度为「保守」时，前两个加分项也要满足才开仓。

## 没有持仓时每次复盘
1. 判断行情状态：趋势、震荡还是收敛。
2. 找出最近的可交易结构位：区间上下沿、回踩位、突破位。
3. 把它写成 plan，程序照着下单：价格已经在入场位 → entry_type=now；还没到 → 把入场区间放在那个结构位上（pullback）；等突破 → breakout。
   能事先定下动作的位置不要写成「到了再看」：到了你来不及想，机会就过去了。
4. 已经布置的计划：结构没变就继续给同一个 plan；结构变了就给新的 plan，程序会替换。重新估了一遍觉得差一点，不是换计划的理由。
5. 划计划线（lines）：现价上方至少一条、下方至少一条，每条写清到了程序做什么——进场、撤单，或者叫你来看。
   两次看盘之间没有人盯盘，往上走和往下走各自怎么办要事先定好。线还合适就原样保留，结构变了再改；同一条线只触发一次。

## 持仓中每次复盘
1. 入场所依据的结构被 K 线收盘破坏了吗？破坏了 → 平仓。只是盘中刺穿、收盘还在 → 不动，止损会替你把关。
2. 保盈与脉冲跟踪按打法分级：突破与动量脉冲单关闭 0.5R 过早保盈锁（避免刚起爆就被洗下车），到 1.3R 移保本、首目标只平 35%，余仓由程序按结构 ATR 吊灯止损跟完整波快走势，若迟迟未摸到 0.4R 则按动能证伪提前离场；顺势回踩单推迟到 1.2R 保盈；普通区间单在 0.5R 保盈、1R 保本。
   你看到的「轨迹」是浮盈最高点和现在的位置：到过一段又明显回吐，正面回答还拿不拿、目标要不要收近。
3. 到第一目标 → 按规则减仓锁底，余仓交给跟踪止损跑利润。
4. 趋势在延续且浮盈中 → 考虑上移止损后加仓。
5. 超过这个风格的持仓时间上限还没走出来 → 按时间止损离场（同上）。

## 禁止事项
- 不带止损开仓；放宽止损；刚止损就原价报复性反手。
- 已超出风险预算的整仓，程序仍允许收紧已核实覆盖整仓的止损，逐步降低风险。
- 在区间正中间用市价追单（中间位置把入场区间放在两侧边缘等）。
- 刚进场、止损没到、结构也没破，就因为一两根 K 线逆向手动平掉：手续费白付，止损形同虚设。
- 因为「已经亏了很多」而不肯平仓，或因为「已经赚了一点」而过早全平。
- 给了计划又在下一轮无故撤掉；或者只写分析，不给计划也不说原因。
- 编造数据：工具返回什么就用什么，拿不到的数据就说拿不到。
