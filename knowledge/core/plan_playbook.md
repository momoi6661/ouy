# 从策略到计划（plan 怎么写）

选定策略后，照下面的写法把它落成 plan。入场区间、止损、目标都取行情快照里的真实价位：
support / resistance、range 的 upper / lower、windows 的 prev_high / prev_low、ema20、swing_highs / swing_lows。

| 策略 | 什么时候用 | entry_type | 入场区间放哪 | 止损放哪 | 目标与管理 |
|---|---|---|---|---|---|
| 收敛突破 | 布林收口蓄势或顺势贴近箱体边界 / 刚放量破位 | breakout 或 now | 边界到外侧 0.3%（已放量破位未跑远用现价） | 边界内侧约 1.8×基准 ATR（留足呼吸防噪音扫损） | 首目标平 35%，余仓不封顶用 ATR 吊灯止损跟完整段脉冲 |
| 动量延续 | 强趋势推进中段，价格浅回踩结构周期 EMA20 | now 或 pullback | EMA20 附近 | EMA20 外侧约 1.4×基准 ATR | 2R 减仓锁底，余仓 ATR 跟踪止损 |
| 趋势回踩 | 大方向明确，价格向近端支撑/阻力回调 | pullback 或 now | 最近支撑、EMA20 或突破位 | 结构位外侧 ≥0.8×基准 ATR | 前高/前低减仓 40%，1.2R 保盈 + ATR 跟踪 |
| 区间高抛低吸 | 宽幅震荡未收口，上下沿清楚 | pullback | 下沿附近做多，上沿附近做空 | 区间外侧 ≥0.8×基准 ATR | 区间中轨平一半，第二目标看对侧 |
| 变盘后回踩 | 5m 刚确认结构反转 | pullback 或 now | 被越过的摆动点附近 | 摆动点外侧 1×ATR | 原极值与 1.5 倍延伸 |

写计划的要点：
- 入场区间要窄，一般不超过止损距离的三分之一：程序在价格碰到离现价近的那一边时就进，盈亏比也按那一边算。
- 止损宁可放宽到结构位之外，也不要为了凑盈亏比贴着入场价。止损宽了仓位会自动变小，每笔亏损金额不变。
- 第一目标取下一个真实的结构位。扣完成本净盈亏比不够，说明这个位置不值得做：换一个离止损更近的入场位，或者换下一个结构，
  不要把目标往够不着的地方挪。
- 一次只有一个计划。区间两头都能做时，先给离现价近、又不逆大方向的那一头；价格走到另一头附近再换。
- 逆大方向的计划：risk_pct 填上限的一半，目标只看最近一个关键位。
- valid_minutes 不填就按交易风格的默认值；结构很快会变的小区间可以填短一些。
- plan 表达不了的做法（区间来回做几轮、网格、翻倍补仓）用 deploy_strategy 直接布置。
