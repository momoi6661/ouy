# 出场与持仓管理

## 止损怎么放
- 放在「判断被证伪」的位置：做多放在回踩低点/支撑带下方，做空放在反弹高点/阻力带上方。
- 再往外留 0.5~1 个 ATR(15m 或 1H) 的缓冲，避免被正常波动扫掉。
- 止损距离通常在 1~3 个 ATR(15m) 之间。太近（< 0.5 ATR）等于送钱，太远说明入场位置不好，宁可不做。
- 止损一旦设好，只能往有利方向移动，绝不放宽。

## 止盈怎么放
- 第一止盈 TP1：最近的反向结构位（前高/前低、区间另一侧、布林带对侧）。到它的净盈亏比（扣掉往返手续费和点差，程序核对）要达到【出手尺度】的下限：保守 2、均衡 1.5、积极 1.2。
- 第二止盈 TP2：更大周期的关键位或 3R 左右。
- 交易所的止盈单挂在最远的那个目标；计划给了两个以上目标时，到第一目标由执行器自动平掉一半。

## 持仓过程中的动作（每次复盘按顺序检查）
1. **判断是否被证伪**：出现下列任一情况，不等止损，立刻市价平仓跑路：
   - 关键支撑/阻力被放量收盘击穿，结构反转（做多时出现 LH+LL）。
   - 入场理由消失（比如回踩入场后 EMA50 被有效跌破）。
   - 出现与持仓方向相反的剧烈异动（单根 15m K 线反向超过 2 ATR 且放量）。
2. **浮盈最高到过 0.5R（保盈线）**：程序直接把止损移到「入场价 + 往返成本」（约 0.12%），被打出来扣费后基本不亏。这一步不等 Worker，模型出错或很慢时也照样执行。
   为什么是 0.5R 而不是 1R：本项目的候选位回测里，约五分之一的单浮盈到过 0.5R 以上、最后却亏到 -0.5R 以下（见 evidence「保盈线回测」）。
   代价也要知道：锁得早会把一部分本来能到目标的单洗出去（日内 75 天回测里，到 0.5R 以上的赢单从 275 笔减到 133 笔），平均每笔从 -0.29R 改善到 -0.15R。
   想给某一笔更多回撤空间（比如波段单、或者明确的趋势单），用 deploy_strategy 的 manage 给这笔写 lock_r（写 0 = 不要），并说明理由。
   **到 1R 浮盈**：执行器把止损移到开仓价；已经被保盈线移得更紧的不会往回放。被保本止损打出来仍会亏掉往返手续费，急行情里还有滑点。
3. **到 TP1**：减仓一半（照计划进场的单执行器自动做），止损移到保本之上，剩余仓位让利润奔跑。
4. **趋势延续**：止损跟随最近的摆动低点（做多）或 1H EMA20 外侧上移，每次只收紧不放宽。
5. **动能衰竭**：RSI 背离、MACD 柱连续缩短、冲高放量长上影——减仓或直接收紧止损到最近摆动点。
6. **时间止损**：进场后迟迟不走（超短线 30 分钟、日内 4 小时，浮盈还不到 0.5R），说明判断不成立，执行器按市价离场；波段单不设时间上限，以 4H 结构是否被破坏为准。
7. **资金费率结算前**：持仓方向要付高额资金费且利润微薄时，考虑提前离场。

## 走势不对时：减仓还是平仓
- 小幅不利但结构没坏 → 维持，止损不动。
- 结构出现疑点（比如回踩比预期深、量能不对）→ 先减仓一半，把风险降下来再看。
- 结构被破坏 → 全平，不犹豫，不等反弹。亏小钱是成本，扛单才是事故。

## 出处
- 用 R（初始风险的倍数）来衡量每一笔的盈亏、先定止损再定仓位：Van K. Tharp《Trade Your Way to Financial Freedom》。
- ATR 吊灯止损：Chuck LeBeau。原版参数是 22 根 K 线的最高价减 3 倍 ATR。
- 「截断亏损、让利润奔跑」对抗的是处置效应——人天生倾向于过早卖出盈利的仓位、死拿亏损的仓位（Shefrin 和 Statman 1985；Odean 1998）。

## 止损后自动反手
- 做法：给 plan 时填 reverse_trigger（反手触发价，放在这笔止损的外侧一点）、reverse_stop（反手单的止损，通常放回原入场位附近）、reverse_target；已有仓位时用 deploy_strategy(kind="reverse")。
- 程序盯着：原仓位亏着被平掉之后，价格在 60 分钟内继续走到触发价，就自动开反方向的单；原仓位是止盈走的、价格冲过触发价太多、或者超时，自动作废。
- 只在「止损被打 = 结构被破坏 = 反方向成立」时用，比如止损放在区间边界或关键前高前低之外。止损只是普通波动位的单不要挂反手：震荡里会被来回打两次。
- 反手单照样过风控，仓位按它自己的止损距离算。
