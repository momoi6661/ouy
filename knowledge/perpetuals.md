# 永续合约要点（欧易 U 本位）

## 合约面值与名义价值
- 合约面值 ctVal：每张合约代表多少标的（BTC-USDT-SWAP 是 0.01 BTC，SOL-USDT-SWAP 是 1 SOL）。名义价值 = 张数 × ctVal × 价格。
- 盈亏按名义价值算，和用了多少保证金、几倍杠杆无关。杠杆只决定占用多少保证金、离强平多远。

## 三种价格：最新价、指数价格、标记价格
- 最新价：这个合约最近一笔成交的价格，K 线图默认画的就是它。
- 指数价格：从多个现货市场加权得到的参考价。
- 标记价格：指数价格加上一个平滑过的基差，用来算未实现盈亏和判断强平。
- 强平只看标记价格，不看最新价；止盈止损单默认按最新价触发。插针时两者会分开：最新价刺到了止损位，标记价格可能还没到，反过来也一样。

## 资金费
- 作用：让合约价格贴住指数。合约比指数贵（溢价）时费率为正，多头付给空头；便宜时为负，空头付给多头。只有结算那一刻持仓的人才收付。
- 结算周期：默认每 8 小时一次（UTC 00:00 / 08:00 / 16:00，北京时间 08:00 / 16:00 / 00:00），部分品种是 4、2、1 小时；
  费率打到上限或下限时欧易会自动把周期缩短一档。

## 资金费率怎么算
- 欧易的公式：资金费率 = clamp[（平均溢价指数 + clamp（利率 − 平均溢价指数，±0.05%））÷（8 ÷ 结算周期小时数），下限，上限]。
- 加密货币合约的利率固定为 0.01%，所以不拥挤时费率稳定在 +0.01% 附近；股票永续的利率是 0，正常水平在 0 附近。
- 上下限每个品种不同（主流币窄、小币和股票永续宽），以 market_get_funding_rate 返回的 maxFundingRate / minFundingRate 为准。

## 快照里的资金费字段
- funding_rate_pct 是本期费率，funding_interval_hours 是结算周期，funding_rate_8h_pct 是折成 8 小时的费率。
- 知识库里说的「0.03%」「0.05%」这些门槛都是 8 小时口径；结算周期更短的品种必须看 funding_rate_8h_pct，否则会把拥挤看轻好几倍。
- 费率的正负只说明哪一边更挤、哪一边在付钱，不是方向信号：强趋势里正费率可以挂很久。怎么用见「拥挤度反转」。

## 持仓量 OI
- 定义：还没有平掉的合约总数。每一张合约都同时有一个多头和一个空头，多头持仓永远等于空头持仓。
  所以 OI 上升不等于「多头变多」，只说明有新仓位在建立；OI 下降说明仓位在平掉或被强平。

## 价格和持仓量一起看
这是期货市场的传统读法，用来确认趋势有没有人接力，不是买卖信号：
- 价格涨 + OI 涨：有新仓位跟着上涨进场，上涨有人接力。
- 价格涨 + OI 跌：上涨主要靠空头平仓推动，缺少新仓，持续性差。
- 价格跌 + OI 涨：有新仓位跟着下跌进场，下跌有人接力。
- 价格跌 + OI 跌：下跌主要靠多头平仓或被强平，是去杠杆，抛压接近用完。
- 价格横盘 + OI 快速堆积：两边都在加仓，随后容易出大波动，方向未定，先别重仓。
同一种组合后面既可能延续也可能反转，要和资金费率、价格结构放在一起看。

## 强平
- 判断标准只有一个：维持保证金率 ≤ 100% 就触发，按标记价格算。仓位越大档位越高，要求的维持保证金越多、能用的杠杆越低。
- 强平发生在保证金亏光之前，还要付强平手续费。界面上的预估强平价会随保证金、仓位、资金费变化，只能当参考。
- 止损和强平是两套互不相干的机制：止损离强平价太近时，可能止损还没触发就先被强平。本项目要求「止损距离% × 杠杆 < 70」就是为了留出这段距离。
- 全仓模式下整个账户的余额都是保证金，单个仓位出事会拖累全部资金，所以更要靠止损而不是靠强平来限制亏损。

## 止盈止损单与滑点
- 止盈止损单到价后以市价成交；剧烈行情下成交价可能比触发价差（滑点）。重大事件前收紧仓位，而不是指望止损精确成交。
- 盘口：买卖盘失衡只作短线参考；大额挂单可能随时撤，不能当支撑阻力用（见「盘口与成交」）。价差异常放大时不用市价单。

## 模拟盘
- 模拟盘有自己独立的盘口和成交，价格与实盘接近但不相同，流动性更差。在模拟盘里验证流程和纪律，不要把模拟盘收益当真。
